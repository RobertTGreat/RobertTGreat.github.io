# RobertTGreat.github.io

Personal portfolio — projects (Warmind), Pleiades products, and design work.

**Live:** https://roberttgreat.github.io/

## Develop

```bash
npm install
npm run dev
```

## Build (static export for GitHub Pages)

```bash
npm run build
# output in out/
```

Deploy is automatic via `.github/workflows/deploy-github-pages.yml` on push to `master` / `main`.
